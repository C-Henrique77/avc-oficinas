# Evidências (prints)

Coloque aqui os arquivos de evidência pedidos no enunciado (nomes sugeridos):

| Arquivo | Como gerar |
|---|---|
| `mvn-test.png` | rode `mvn test` e tire print mostrando `Tests run: ..., Failures: 0, Errors: 0` e `BUILD SUCCESS` |
| `postman-colecao-oficial.png` | importe a coleção oficial da professora, rode pelo **Runner** e tire print do resultado (todas as requisições passando) |
| `postman-cenario-proprio.png` | importe `postman/cenario-proprio.postman_collection.json`, rode pelo Runner e tire print |

Dica: rode a coleção oficial **sempre com o banco recém-carregado** (script da professora), para os dados iniciais
estarem como o Postman espera.
